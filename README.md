# JJ's Memory Match

A bright, friendly memory matching game made for JJ — a 7-year-old playing on a phone. Built with Kiro.

## What the game is

Flip over cards two at a time and find the matching pairs. There are **12 cards** laid out in a **4×3 grid** that hide **6 pairs** of fun emoji (animals, space, and food). The emoji are picked at random every game, so it's a little different each time. Try to find all the pairs in as few moves as you can!

## How to play

1. Tap a card to flip it over.
2. Tap a second card.
   - **Match!** 🎉 The two cards stay face-up with a happy green glow.
   - **No match?** The cards flip back over after a moment — remember where they were!
3. Keep going until all 6 pairs are found.
4. Watch the **Moves** counter at the top to see how many tries you've used.
5. When you find every pair, a celebration banner shows your final move count. Tap the big **Play Again** button to shuffle a brand-new game.

## How to open it

Just open **`index.html`** in any web browser — double-click the file, or drag it into a browser window. On a phone, open the file in your mobile browser.

That's it. No installation, no internet connection, and no setup needed — the whole game lives in a single file and works completely offline.
